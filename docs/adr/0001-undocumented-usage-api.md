# 무문서 API `GET https://ollama.com/api/usage`를 1차 데이터 소스로 채택

Ollama는 계정 사용량 조회의 공식 문서를 제공하지 않는다(OpenAPI 스펙에 엔드포인트가 없음). 그러나 엔드포인트의 실존과 사용법이 스태프 코멘트로 공개돼 있고(이슈 #17451), 비인증 probe로 확인됐으므로 이를 1차 데이터 소스로 채택한다. 스키마나 레이트 리밋의 공식 보장이 없다는 전제에서, 파서는 필드 누락·추가에 관대하게 작성하고 응답 원문을 볼 수 있는 디버그 뷰를 유지한다. 스크래핑(취약)과 응답 토큰 카운트 누적(근사치)은 1차 소스에서 배제했다. 관측 기록과 스키마 증거는 `docs/research/ollama-cloud-usage-credits-api.md` 참조.
