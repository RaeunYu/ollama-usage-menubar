# API 키는 Keychain에만 저장한다

설정 파일은 사용자가 직접 자주 열어 편집하도록 만든 것(한국어 설명 키 동반)이고, 클라우드 동기화나 공유로 새어 나갈 수 있으므로 API 키를 담지 않는다. 키는 macOS Keychain에만 저장하며 메뉴의 "API 키 설정…"에서 입력받는다. 첫 실행에 설정 창을 자동으로 띄우는 온보딩은 채택하지 않는다 — 다른 작업 중 갑작스러운 창 노출이 방해가 되기 때문(2026-09-03 사용자 결정; 안내는 드롭다운의 키 오류 상태가 담당한다). 편의상 설정 파일에 두는 대안을 고려했으나 평문 키 노출 리스크가 이긴다.
