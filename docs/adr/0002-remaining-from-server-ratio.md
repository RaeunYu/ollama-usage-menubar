# 잔여 비율은 서버 제공 비율을 1순위로 쓰고 activity.cost는 표시에 쓰지 않는다

`limits.monthly.usage`는 [사용 크레딧 ÷ 제공 크레딧] 비율임이 사용자 실측으로 확인됐다($0.14/$60 ≈ 0.002). 잔여 비율 = `1 − usage`로 서버 값을 그대로 쓰고, 달러 표시는 설정 파일의 제공 크레딧과 조합해 계산한다. `activity.cost`는 포맷·의미가 변동할 수 있어 표시에 쓰지 않고 디버그 관찰용으로만 둔다. 앱이 직접 사용액을 나눠 잔여를 만들면 가격 개편 때 두 곳이 동시에 깨지므로, 계산 주체를 서버 한 곳으로 고정한다.
